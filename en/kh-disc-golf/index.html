Version 0.9.1 · build 39
Released to closed Alpha testing on 5 November 2026

More reliable backups and safer link handling

Build 39 strengthens user-data preservation and app reliability. The fixes have been tested in separate Android test environments.

Backups

The latest changes are included

Backups now reliably include even the most recent game-data changes and the correct database version. Restoring, exporting a new backup and restoring it again has been tested with user data preserved.

Game-data preservation

Unexpected round records are not silently removed

If an inconsistency is found in round data, the records are preserved for later safe handling instead of being deleted automatically.

Link security

Malformed links are handled more safely

Link handling has been hardened against malformed and unusually long input, reducing the risk of freezes and crashes.

Android compatibility

Ready for newer Android requirements

Android 16 / API 36 compatibility and the 16 KB memory page size have been tested in a separate Android environment.

Google Play updates

Update normally through Play Store

Approved Alpha testers install and update the Play-distributed app through Google Play.

Open in Google Play. The page is available to an approved tester signed in with the correct Google account.

Production access granted – Alpha testing continues

Google Play granted production release access on 13 October 2026. This does not mean that the app has been released on the public production track. The version currently distributed to users is closed Alpha release 0.9.1/build 39.

Build 39 (0.9.1) was released to closed Alpha testing on 5 November 2026. Practical testing and final polishing continue before the public release. The goal is to proceed to a general production release after successful usage trials in the closed Alpha; open testing is not currently a required intermediate phase. The app is still in Alpha, so defects may be found.

The closed test group will remain important after production release: major future features can be preview-tested with the group before wider distribution.
